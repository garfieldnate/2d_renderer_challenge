The 2D Renderer Challenge

Build a complete 2D vector renderer from nothing, in any language, test first: lines, fills, curves, compositing, gradients, images, clips, strokes, dashes, type and SVG, with every pixel written by your own code.

Twenty-one chapters in six parts make the main track, and each part leaves you with something that works on its own. Two bonus tracks go further out. Every step comes with Gherkin scenarios and every render with a reference image, so the tests always tell you when you've got it right. Start with chapter 0, which explains how the book works and where you can stop.
